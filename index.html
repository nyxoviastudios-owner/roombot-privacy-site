Personal content workflow

ROOMBOT

ROOMBOT is a personal workflow for preparing room-inspiration and home-decor Pinterest content. The operator reviews each proposed Pin and chooses whether to publish it.

Privacy Policy

Effective date: 13 October 2026

This page explains how the operator of ROOMBOT handles information while developing and using the workflow. ROOMBOT is currently a personal project, not a public user-account service.

Information processed

The operator may enter content ideas, draft Pin text, product URLs, and affiliate tracking links into the workflow. If integrations are enabled, ROOMBOT may process the minimum information needed to perform the requested operation through the services described below.

Third-party services

  • Pinterest: If the Pinterest API is connected, the workflow may send approved Pin content and access the account or board information needed for the requested action. Pinterest handles information under its own terms and privacy policy.
  • Amazon Associates: Pins may contain Amazon affiliate links. Clicking them takes visitors to Amazon, which handles browsing and purchases under Amazon's own policies.
  • AI text services: If an AI text provider is connected, prompts and relevant product details may be sent to generate draft copy. The operator should review the provider's terms and data practices before enabling it.
  • Hosting and workflow tools: The privacy page may be hosted by GitHub Pages. The workflow may run locally or use a database/storage provider chosen by the operator. Those providers may process technical information under their own policies.

Images and content rights

The initial workflow is intended to use original images or images for which the operator has permission. Automated AI image generation is not enabled at this stage. Content should not be uploaded or published unless the operator has the necessary rights.

Storage, security, and retention

Integration credentials should be stored in the workflow tool's credential manager and never published in source files or Pin descriptions. The operator should restrict credential access, avoid retaining unnecessary API response data, and configure workflow-history and database retention before enabling API access. No system can be guaranteed completely secure.

Visitors to this page

This page does not intentionally provide visitor accounts, forms, or operator-run advertising analytics. GitHub Pages may process technical request information as described in GitHub's policies.

Children

ROOMBOT is not designed as a service for children, and the operator does not knowingly collect personal information from children through this page.

Changes to this policy

This policy may be updated when the workflow or its integrations change. The effective date above will be revised when material changes are made.
